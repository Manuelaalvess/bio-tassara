# Tassara Otorrino — Link da Bio

Página de link único (estilo Linktree) para a bio do Instagram da Clínica Tassara Otorrino, em Nova Friburgo, RJ.

Site estático (HTML/CSS/JS puro, sem build), responsivo, com:
- Botão de agendamento direto pelo WhatsApp
- Atalhos para ligação e Instagram
- Lista da equipe, exames realizados e convênios aceitos (em acordeões)
- Card de localização com link para o Google Maps
- Card de agendamento com o Dr. André Viana (dermatologista, mesmo espaço)

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
python -m http.server 8000
```
